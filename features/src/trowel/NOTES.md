Trowel runs under [s6-overlay](https://github.com/just-containers/s6-overlay) as the selected devcontainer user, with a starter configuration at `/etc/trowel/config.yml` that listens on `127.0.0.1:8080` and connects to `nats://127.0.0.1:4222`. Bind-mount a project directory holding `config.yml` over `/etc/trowel` when needed; Trowel reloads the file when it changes. A user with sudo access can reload with `sudo /command/s6-svc -h /run/service/trowel` or restart the service with `sudo /command/s6-svc -r /run/service/trowel`. The service loads `NAME=value` lines from `/run/openbao/secrets/trowel.env` when that file exists, and waits for it when the [OpenBao](https://openbao.org) Agent Feature renders it. When the [Ansible](https://www.ansible.com) Feature is installed, the service also waits for its `ansible-setup` oneshot to succeed before it starts; without that Feature, nothing changes.
